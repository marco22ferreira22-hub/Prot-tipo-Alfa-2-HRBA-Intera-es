# HRBA Interações Medicamentosas

**Protótipo expandido de checagem de interações medicamentosas potenciais (IMPs)**  
Serviço de Traumatologia e Ortopedia – Hospital Regional do Baixo Amazonas (HRBA)

---

## Sobre

Ferramenta de suporte à equipe multiprofissional, construída a partir da **Padronização de Medicamentos do HRBA** e da lista oficial de **Medicamentos de Alta Vigilância (MAVs)**.

Esta versão amplia significativamente a quantidade de medicamentos disponíveis para seleção, cobrindo as principais classes terapêuticas presentes no manual institucional do hospital.

---

## Conteúdo

- Ampla lista de medicamentos da padronização oficial do HRBA
- Foco nos fármacos utilizados no Serviço de Traumatologia e Ortopedia
- Classificação de gravidade (Contraindicado / Maior / Moderada / Menor)
- Mecanismo (farmacocinético ou farmacodinâmico)
- Contexto clínico em ortopedia/trauma
- Monitoramento, alternativas e manejo
- Aba completa de MAVs (Sonoridade Semelhante + Potencialmente Perigosos)
- Relatório para impressão / PDF
- Arquivo 100% estático (HTML + CSS + JavaScript)

---

## Como usar

1. Abra o `index.html` no navegador
2. Filtre por nome ou classe terapêutica
3. Selecione 2 ou mais medicamentos
4. Clique em **Verificar Interações**
5. Use o botão **Relatório** para imprimir ou salvar em PDF

---

## Publicação no GitHub Pages

1. Crie um repositório público no GitHub
2. Faça upload do `index.html` e deste `README.md`
3. Em **Settings → Pages**, selecione a branch `main` e a pasta `/ (root)`
4. Aguarde 1–2 minutos
5. O site estará em: `https://seu-usuario.github.io/nome-do-repositorio/`
